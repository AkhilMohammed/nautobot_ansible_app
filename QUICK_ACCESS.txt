⚡ CI/CD PIPELINE - AUTOMATIC ZERO-DOWNTIME DEPLOYMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
To deploy changes with ZERO DOWNTIME:

1. Edit configuration:
   vim group_vars/dev/nautobot.yml

2. Add a plugin (example):
   nautobot_plugins:
     - name: nautobot_device_lifecycle_mgmt
       pip_name: nautobot-device-lifecycle-mgmt

3. Commit and push:
   git add group_vars/dev/nautobot.yml
   git commit -m "Add lifecycle management plugin"
   git push origin main

4. Pipeline automatically:
   ✅ Detects changes
   ✅ Builds new image (if plugins changed)
   ✅ Updates ConfigMap
   ✅ Performs rolling update (zero downtime!)
   ✅ Runs health checks
   ✅ Rolls back if failed
